# 符文石設計稿（星蝕·解）

> 狀態：**設計稿，等你確認後才實作**。數字都可以改，最後一節列了需要你決定的地方。

## 一、鑲在哪裡

| 項目 | 內容 |
|---|---|
| 符文孔 | 武器的三個「星蝕·解」孔，在說話之島的符文師佐爾頓那裡開（已完成）。 |
| 第一孔「墜蝕·解」 | 消耗原版席琳遺骸 8 套。 |
| 第二孔「刻解·骸」 | 消耗夢域席琳遺骸 8 套。 |
| 第三孔「瘴骸·破」 | 鎖定中。 |
| 什麼時候生效 | 武器裝在**主手**時，孔裡的符文生效。副手、背包、倉庫裡的都不算。 |
| 誰拿到效果 | 拿這把武器的人：玩家或傭兵都可以。寵物類的效果只算玩家自己的寵物。 |
| 同一把武器的限制 | 不能鑲兩顆同名的符文；職業符文一把最多一顆。 |
| 鑲嵌 | 在佐爾頓那裡鑲，免費。 |
| 換掉舊的 | 舊符文直接碎掉；或付席琳結晶 500 把它完整取下來（見第七節問題 3）。 |

## 二、符文的階級與取得

| 階級 | 顏色 | 掉落 |
|---|---|---|
| 一般 | 灰白 | 席琳夢域鏡的頭目 1%；瘋狂席琳謀反者副本的頭目 3% |
| 稀有 | 藍 | 夢域四龍巢穴的最終龍 5%；謀反者副本的最終頭目 5% |
| 傳說 | 紅 | 最終頭目席琳每次通關 10%；謀反者副本的最終頭目 1% |

**佐爾頓合成**：3 顆同階的符文加席琳結晶 100，可以換 1 顆高一階的符文（隨機）。傳說符文不能再往上合。

## 四、符文之語（兩孔組合，順序有差）

第一孔和第二孔照下面的順序鑲，會多出組合效果。第三孔開放後，再加三顆的組合。

| 組合 | 名稱 | 額外效果 |
|---|---|---|
| 夢 → 魘 | 夢魘 | 夢域席琳套裝的百分比效果再 +10%。 |
| 雷 → 裂 | 雷裂 | 魔法二次傷害的機率從 20% 提高到 35%。 |
| 盾 → 罩 | 壁壘 | 物理、魔法傷害再各 −5%。 |
| 泉 → 飲 | 甘露 | 一次喝三罐只扣 2 瓶。 |
| 尋 → 穗 | 拾荒者 | 材料掉落再 +20%。 |
| 濺 → 破 | 碎陣 | 濺射的那一下也無視 50% 減傷。 |

## 五、平衡

- **最終頭目**：
  - 時間關卡保證任何組合至少打 10 分鐘，攻擊類符文只會讓玩家比較早打到關卡。
  - 減傷類受 75% 上限限制，不會變無敵。
- **攻擊類的估算**：「濺」「破」「斬」全上，對頭目的有效輸出大約 +35～45%。
  - 這會讓目前 7.5 分的職業往 8.5 分靠近。
  - 實作後我會用八職業的對戰工具重跑一次，再調整數字。
- **「裂」的影響**：
  - 預設鎖住二次傷害爆擊，等於削弱現在所有靠二次傷害的打法。
  - 主要是戰士的血怒狂斧第二輪、幻術士的二次傷害、連擊、雙重破壞。
  - 這個要你確認（第七節問題 1）。

## 七、需要你決定

1. **「二次傷害可以爆擊，現在鎖定」指的是哪些？**
   - 我的理解：所有「額外追加的那一下」預設都不吃爆擊，只有鑲「裂」才恢復。
   - 包括連擊、雙重破壞的第二下、遺物的追加傷害、血怒狂斧的第二輪、幻術士的二次傷害。
   - 這等於先削弱現有打法。要這樣做嗎？還是只鎖某幾種？
2. **「濺射能力開啟」**
   - 我做成：不需要爆擊率 80% 也能濺射 30%；滿 80% 時濺射從 50% 提高到 80%。
   - 還是你的意思是：現在的爆擊滿 80% 濺射改成「要鑲符文才有」？
3. **換符文**：舊的直接碎掉，還是可以付席琳結晶取回？
4. **掉落率**：第二節的掉落率可以嗎？
5. **職業符文**：「增益常駐／攻擊每 8 秒自動放」這個方向對嗎？
6. **符文名稱**：用單字（穗、尋、盾…）可以嗎？要不要換成其他風格？
